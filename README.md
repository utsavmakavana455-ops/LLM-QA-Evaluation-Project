
# LLM QA Evaluation Project

## Project Overview

This project demonstrates my practical experience as an **LLM / AI QA Reviewer**, where I evaluated AI-generated responses against their corresponding prompts.

The project contains **20 QA evaluation records**. For each record, I reviewed the prompt and generated responses to determine which response was more **accurate, relevant, complete, clear, and suitable for the requested task**.

The goal was to assess the overall quality of AI responses and make a structured QA decision based on defined evaluation criteria.

---

## My Role

**Role:** QA Reviewer / LLM Evaluator

As a QA Reviewer, I was responsible for:

* Reviewing prompts and AI-generated responses
* Understanding the exact requirements of each prompt
* Comparing responses against the requested task
* Checking factual accuracy and correctness
* Verifying instruction following
* Evaluating relevance and completeness
* Checking clarity and response quality
* Identifying errors and inconsistencies
* Determining which response was more suitable
* Providing a clear rationale for the QA decision

---

## QA Evaluation Criteria

Each response was reviewed based on the following criteria:

| Criteria                  | What I Checked                                              |
| ------------------------- | ----------------------------------------------------------- |
| **Accuracy**              | Whether the information and answer were correct             |
| **Relevance**             | Whether the response addressed the actual prompt            |
| **Instruction Following** | Whether all prompt requirements were followed               |
| **Completeness**          | Whether all required information was provided               |
| **Clarity**               | Whether the response was understandable and well-structured |

---

## Evaluation Process

The QA workflow followed these steps:

**1. Prompt Review**
Understand the user's request and identify all explicit requirements.

**2. Response Review**
Read and analyze the AI-generated responses.

**3. Requirement Validation**
Check whether each response followed the instructions given in the prompt.

**4. Accuracy Check**
Verify factual information, reasoning, calculations, and other relevant content.

**5. Comparative Evaluation**
Compare the responses against the QA criteria.

**6. Error Identification**
Identify issues such as factual errors, instruction-following problems, incomplete answers, irrelevant content, formatting issues, or reasoning problems.

**7. QA Decision**
Select the response that better satisfies the requirements.

**8. Reviewer Rationale**
Document the reasoning behind the evaluation and final selection.
